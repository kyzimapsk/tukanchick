Web port for board game: Trails of Tucana

## Запуск

Нужен Node.js 22.15+.

```bash
npm ci

# игра + сервер мультиплеера одним процессом: http://localhost:5000
npm run serve
```

Разработка (клиент с hot reload на :8080, websocket проксируется на сервер :5000):

```bash
npm run server:build && npm run server   # терминал 1
npm start                                # терминал 2
```

`npm run typecheck` проверяет типы клиента и сервера.

## Мультиплеер

Все игроки одновременно играют на своих картах с одними и теми же картами местности
и раскладкой городов, как в настольной версии. Сервер (`server/`) раздаёт карты,
проверяет каждый ход теми же правилами, что и клиент (`src/game/board.ts`), и ведёт общий счёт.

Хост создаёт лобби и сообщает остальным 6-символьный ID; в лобби до 6 игроков.

Переменные окружения сервера:

| переменная        | по умолчанию       | назначение                                                     |
|-------------------|--------------------|----------------------------------------------------------------|
| `PORT`            | `5000`             | порт                                                           |
| `HOST`            | `0.0.0.0`          | интерфейс                                                      |
| `STATIC_DIR`      | `dist`             | собранный клиент; пустая строка - не раздавать статику         |
| `ALLOWED_ORIGINS` | тот же хост        | список сайтов через запятую, с которых можно подключаться      |

Если клиент хостится отдельно от сервера, адрес websocket задаётся при сборке:
`MULTIPLAYER_URL=wss://example.com/exchange npm run build`. По умолчанию клиент
подключается к `/exchange` на своём же хосте (`wss://` для https-страниц).

В продакшене сервер ставится за reverse proxy с TLS (nginx, Caddy и т.п.).

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает клиент и публикует его при каждом пуше в `master`
(в настройках репозитория: Settings -> Pages -> Source: GitHub Actions).

Pages раздаёт только статику, поэтому там работает одиночная игра. Для мультиплеера сервер
поднимается отдельно (`STATIC_DIR="" ALLOWED_ORIGINS=https://<user>.github.io npm run server`),
а его адрес указывается в переменной репозитория `MULTIPLAYER_URL` (`wss://<host>/exchange`).

## Управление

- построить дорогу - протянуть от гекса к соседнему гексу (мышью или пальцем);
- SKIP - пропустить ход, если подходящих мест нет;
- зум - колесо мыши или щипок двумя пальцами;
- перемещение карты - правая/средняя кнопка мыши или два пальца.
